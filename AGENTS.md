# Instructions du projet

Lire `SPEC.md` et `CONTENT.md` avant toute modification.

- Le 28 octobre 2026, l’utilisateur a autorisé la création du dépôt GitHub public Youplala/changeandprojects et le déploiement de la V1 sur GitHub Pages. Préserver les versions V2 et V3 séparées. Ne pas utiliser Sites.
- Conserver Astro + TypeScript + CSS, en génération statique. Aucun CMS, aucune base de données, aucun compte, réservation, paiement, blog, chatbot ou formulaire complexe.
- Respecter la direction éditoriale sobre, humaine et aérée : ivoire, rouge profond, anthracite et bronze.
- Garder les contenus structurés et les formations dans `src/data/site.ts`.
- Ne jamais inventer de programmes, tarifs, durées, certifications, coordonnées ou références clients. Les pistes non validées restent `published: false`.
- Le modèle des fiches vérifie les champs nécessaires avant génération. Préserver cette protection et ses tests.
- Aucun portrait fictif. L’utilisateur a demandé de remplacer l’emblème provisoire par une photographie de la vraie statue de Giacometti, détourée sur fond transparent, pour cette maquette locale. Préserver cette direction et ses crédits ; les droits de reproduction devront être vérifiés avant toute publication commerciale.
- Ne pas installer de traceur, cookie applicatif ni dépendance réseau pour l’affichage. Les polices sont locales.
- Conserver les mentions légales au statut de brouillon jusqu’à validation et conserver le blocage d’indexation.
- Vérifier les modifications avec `npm run check`, `npm run build` et `npm test`, ainsi que dans le navigateur aux tailles pertinentes. Le serveur de développement doit rester accessible à l’utilisateur pour examiner la maquette.
